## 1. INA219 旁路 MOS 引脚迁移（PE3/PE2 → PA2/PA10）⚠️ 高优先

> 硬件已迁移：主电旁路 MOS 现在 PA2，备电旁路 MOS 现在 PA10。
> bypass 高 = 正常供电（电流走旁路），bypass 低 = 电流过 INA219 采样电阻可测量。

### 1.1 主电通道 (CH_MAIN, PA2)
- [ ] 上电后用万用表测 PA2，应为 **高电平**（≈3.3 V，旁路开 = 正常供电）
- [ ] 上位机下发"开启功耗测试（低功耗模式）" → PA2 应被拉 **低**，INA219 读到正常电流
- [ ] 关闭功耗测试 → PA2 回到 **高**，主电恢复正常供电
- [ ] 用 USB 电流表实测进入低功耗后整机功耗 < 100 µA（粗略门槛，看实际电路）

### 1.2 备电通道 (CH_NB, PA10)
- [ ] 开启备电（`board_backup_power_on`）后 PA10 应为 **高**
- [ ] 调用 `ina219_measure_enable(INA219_CH_NB)` 后 PA10 应被拉 **低**
- [ ] INA219 备电通道读数随上述切换变化合理

### 1.3 旧脚位回归测试
- [ ] PE3、PE2 现已不被任何代码主动写，应保持复位默认（可悬空 / 上拉到任意值），不影响系统

## 3. board 层 detect 封装迁移（commit `a305114`）

每个 detect 函数都换了名字但写的是同一个物理脚，逐项确认 ADC 读数与 v4.1.0 一致：

| 业务 | 物理脚 | 旧 API | 新 API |
|---|---|---|---|
| 主电检测 (ExV2) | PC8  | `board_external_voltage_2_*` | `board_main_volt_detect_*` |
| 第三节点 (ExV3) | PC9  | `board_external_voltage_3_*` | `board_third_node_detect_*` |
| 表 3.3V (ExV6) | PD11 | `board_external_voltage_6_*` | `board_3v3_detect_*` |
| RTC 电池 (ExV5) | PE6  | `board_external_voltage_5_*` | `board_rtc_battery_detect_*` |
| 阀 R (ExV7) | PC11 | `Board_Enable_Valve_Read_R` | `board_valve_r_detect_*` |
| 阀 B (ExV8) | PC5  | `Board_Enable_Valve_Read_B` | `board_valve_b_detect_*` |
| 表 3.3V→FT (EN_METER_3V3) | PA1 | `test_meter_board_power_ctr` | `board_meter_board_3v3_to_ft` |

- [ ] `read_board_second_node_voltage_mv` 读数与上一版一致（±50 mV 内）
- [ ] `read_board_third_node_voltage_mv` 读数一致
- [ ] `read_board_3v3_voltage_mv` 读数一致
- [ ] `read_rtc_battery_voltage_mv` 读数一致
- [ ] `read_valve_r_voltage_mv` 读数一致（开/关阀全过程）
- [ ] `read_valve_b_voltage_mv` 读数一致（开/关阀全过程）
- [ ] `meter_board_3V3_enable_to_ft(0/1)` 表板供电按预期通断
