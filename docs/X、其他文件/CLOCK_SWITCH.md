# 系统时钟一键切换指南

## 超简单配置方法

### 🎯 只需要修改一个数字！

**文件位置：** `MF-config/Inc/mf_config.h`

**找到这行：**
```c
#define SYSTEM_CLOCK_MHZ    32      // ← 在这里修改数字：8, 16, 24, 32
```

### 🔧 配置选项

| 数字 | 时钟频率 | 用途 |
|------|----------|------|
| `8` | 8MHz | 🔧 红外通信优化模式 |
| `16` | 16MHz | ⚡ 平衡模式 |
| `24` | 24MHz | 🚀 高性能模式 |
| `32` | 32MHz | 🏎️ 默认模式 |

### 📝 使用步骤

1. **打开文件：** `MF-config/Inc/mf_config.h`
2. **找到配置行：** `#define SYSTEM_CLOCK_MHZ    32`
3. **修改数字：** 把 `32` 改成 `8`（如果想尝试红外优化）
4. **保存文件**
5. **重新编译：** `cmake --build build`
6. **烧录测试**

### 🔄 快速切换示例

**当前配置（32MHz）：**
```c
#define SYSTEM_CLOCK_MHZ    32      // ← 在这里修改数字：8, 16, 24, 32
```

**改为8MHz（红外优化）：**
```c
#define SYSTEM_CLOCK_MHZ    8       // ← 在这里修改数字：8, 16, 24, 32
```

### 📊 启动时会显示配置

```
=== 系统时钟配置 ===
软件版本: v1.5.0
配置值: SYSTEM_CLOCK_MHZ = 8
系统时钟: 8MHz (红外优化模式)
实际频率: 8000000 Hz
==================
```

### ⚠️ 重要提示

- **只能填写：** 8, 16, 24, 32
- **填错会编译报错**，非常安全
- **修改后必须重新编译**
- **如果有问题立即改回32**

### 🎯 红外问题排查建议

1. **第一步：** 改成 `8` 试试
2. **如果8有改善：** 可以试试 `16`
3. **如果还是有问题：** 改回 `32` 检查硬件

就这么简单！😄
