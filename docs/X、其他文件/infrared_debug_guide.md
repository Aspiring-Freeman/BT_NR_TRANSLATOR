## 排查步骤

### 1. 硬件连接检查
- **红外发射器**：检查红外LED是否正常工作
- **红外接收器**：检查红外接收模块是否正常
- **电源供电**：确认红外模块供电正常
- **信号线路**：检查UART通信线路

### 2. 水表状态检查
- **水表是否上电**：确认水表处于工作状态
- **红外接收窗口**：确认红外窗口没有遮挡
- **距离和角度**：调整红外发射器与水表的距离和角度

### 3. 协议参数检查
当前发送的协议：
```
68 AA AA AA AA AA AA 00 0A 02 12 00 31 20 00 30 D4 16
```

分析：
- 帧头：68
- 表地址：AA AA AA AA AA AA (广播地址)
- 控制码：00
- 数据长度：0A
- 功能码：0x2031 (查询表号)
- 校验和：D4
- 帧尾：16

这个协议格式是正确的。

### 4. 时序问题检查

- 单步超时：通常设置为 10000ms

### 6. 手动测试建议

可以尝试：
1. **单独测试红外通信**：使用示波器或逻辑分析仪查看红外信号
2. **更换水表**：使用已知正常工作的水表测试
3. **缩短距离**：将红外发射器贴近水表红外窗口
4. **检查波特率**：确认红外通信波特率设置正确

### 7. 常见问题和解决方案

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 完全无响应 | 硬件连接问题 | 检查红外硬件连接 |
| 偶尔有响应 | 信号弱或距离远 | 调整位置，增加发射功率 |
| 协议格式错误 | 软件bug | 检查协议生成函数 |
| 超时时间太短 | 水表响应慢 | 增加超时时间 |

### 8. 下一步建议

如果问题持续存在，建议：
1. 暂时增加超时时间到30秒测试
2. 添加重试机制（如果当前没有）
3. 考虑使用不同的查询协议
4. 检查水表型号是否支持该协议

昨天能工作今天不能工作，最可能的原因是：
- **硬件连接松动**
- **环境干扰增加**
- **水表状态改变**
- **电源电压波动**

建议先检查这些基础问题。
