# F003协议水表返回数据格式

## 协议概述
F003是测试专用协议，用于获取水表的各种状态和测量数据。

## 数据帧格式
| 字段 | 长度(字节) | 说明 |
|------|------------|------|
| 帧开始标识 | 1 | 0x68 |
| 表具标识 | 6 | 水表地址 |
| 协议类型 | 1 | 0x00 |
| 协议版本号 | 1 | 0x00 |
| 协议控制码 | 1 | 0x82(应答) |
| 帧长度 | 2 | 小端格式，总帧长度 |
| 数据标识 | 2 | 0xF003 |
| 消息序号 | 1 | 通常为0x00 |
| 数据域 | 变长 | 见下表详细格式 |
| CRC校验 | 2 | 小端格式 |
| 帧尾 | 1 | 0x16 |

## 关键字段说明

### 电压字段
- 主电电压和备电电压采用小端格式，单位为mV
- 示例：0x10 0x0E = 3600mV = 3.6V

### 状态字段
- 大部分状态字段使用0/1表示异常/正常
- CSQ信号强度范围通常为0-31，数值越大信号越好

### 标识字段
- IMEI、IMSI、ICCID为字符串格式，存储为ASCII码
- LoRa密钥为16字节二进制数据

### 流量字段
- 超声瞬时流量为4字节小端格式
- 单位和精度需要根据具体水表规格确定

## 协议校验
F003协议使用CRC16校验，校验范围为从帧头到数据域结束，不包括CRC和帧尾字段。
