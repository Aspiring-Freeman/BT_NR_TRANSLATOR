通信流程说明

① Idle（空闲）：总线空闲时，SCL 和 SDA 均被上拉电阻拉至高电平。

② START：SCL 保持高电平期间，SDA 产生下降沿，宣告通信开始。

③ 地址帧：主机发出 7 位设备地址 + 1 位 R/W（读写）标志，共 8 个时钟周期。

④ ACK：每 8 位数据后，接收方在第 9 个时钟周期拉低 SDA 表示确认。

⑤ 数据帧：一个或多个字节，同样每字节后跟一个 ACK。

⑥ STOP：SCL 保持高电平期间，SDA 产生上升沿，宣告通信结束。

谁控制 SDA？

正常数据传输时：发送方（主机写数据时是主机，从机写 ACK 时是从机）控制 SDA。

ACK 期间：控制权交给接收方。主机释放 SDA（SDA 变高），从机将其拉低表示 ACK，或不拉低表示 NAK。

读操作时：地址帧 + ACK 由主机/从机协作；数据阶段由从机发送数据，主机提供 ACK。

这种控制权的动态切换是 I2C 协议最精妙也最容易混淆的地方。

START 条件时序 START CONDITION
START 条件是每次 I2C 通信的起点，定义为：在 SCL 保持高电平期间，SDA 出现下降沿。此时总线被主机独占，进入"忙"状态。

// START 条件详细时序图（含所有参数标注）

tHD;STA
Hold Time for (repeated) START condition
SM: ≥ 4.0 µs FM: ≥ 0.6 µs FM+: ≥ 0.26 µs
从 SDA 下降沿（START 事件）到 SCL 下降沿之间的最小时间。 在这段时间内 SCL 必须保持高电平，以确保总线上所有设备都能识别 START 条件。 过短会导致某些慢速设备无法检测到 START 信号。
tBUF
Bus Free Time Between STOP and START
SM: ≥ 4.7 µs FM: ≥ 1.3 µs FM+: ≥ 0.5 µs
上一次 STOP 条件结束后，到下一次 START 条件开始之间，总线必须空闲的最小时间。 这是给总线上所有设备"复位"和准备接收的窗口期。 SDA 和 SCL 都必须保持高电平。
tf （SDA）
SDA Fall Time（下降时间）
SM: ≤ 300 ns FM: ≤ 300 ns FM+: ≤ 120 ns
信号从高电平的 70%（VIH）下降到低电平的 30%（VIL）所需的时间。 由驱动器的输出能力和总线电容共同决定。 过慢说明驱动能力不足，过快可能引起振铃（需串联小阻尼电阻）。
💡 为什么 START 定义为"SCL 高时 SDA 下降"？
I2C 数据有效期规则规定：SCL 高电平期间，SDA 必须保持稳定（变化只能在 SCL 低时发生）。 因此，"SCL 高时 SDA 变化"这一特殊事件被协议保留用作控制信号——下降沿就是 START，上升沿就是 STOP。 这样设计无需额外信号线，就能在数据流中插入控制帧。
数据位时序 DATA BIT TIMING
数据位是 I2C 通信最核心的重复单元。每一位的有效期在 SCL 高电平期间，SDA 的变化必须严格在 SCL 低电平期间完成。

// 单个数据位的完整时序参数（以连续两位为例）

tHIGH
HIGH Period of the SCL Clock
SM: ≥ 4.0 µs FM: ≥ 0.6 µs FM+: ≥ 0.26 µs
SCL 高电平持续的最短时间。这段时间内，SDA 上的数据必须保持稳定，接收方在此期间采样数据。时间过短会导致接收方来不及采样。
tLOW
LOW Period of the SCL Clock
SM: ≥ 4.7 µs FM: ≥ 1.3 µs FM+: ≥ 0.5 µs
SCL 低电平持续的最短时间。这段时间是发送方改变 SDA 数据（进行位切换）的窗口，必须足够长以完成 SDA 的建立（tSU;DAT）和保持（tHD;DAT）。
tr
Rise Time of both SDA and SCL Signals
SM: ≤ 1000 ns FM: ≤ 300 ns FM+: ≤ 120 ns
信号从低电平 30% 上升到高电平 70% 所需的时间。由上拉电阻 × 总线电容（RC）决定。上拉电阻越小、电容越小，tr 越快。计算公式：tr ≈ 0.847 × Rp × Cb
tf
Fall Time of both SDA and SCL Signals
SM: ≤ 300 ns FM: ≤ 300 ns FM+: ≤ 120 ns
信号从高电平 70% 下降到低电平 30% 所需时间。由驱动器的灌电流（Sink Current）能力决定，通常比 tr 快得多。tf 不受上拉电阻影响，受限于驱动器输出晶体管。
tHD;DAT
Data Hold Time
SM: ≥ 0 ns, ≤ 3.45 µs FM: ≥ 0 ns, ≤ 0.9 µs FM+: ≥ 0 ns
SCL 下降沿之后，SDA 上的数据还需要继续保持有效的最小时间。理论最小值为 0ns，但实际中受传播延迟影响应 ≥ 0。上限是为防止误触发 START/STOP 条件。
tSU;DAT
Data Setup Time
SM: ≥ 250 ns FM: ≥ 100 ns FM+: ≥ 50 ns
SDA 数据稳定后到 SCL 上升沿之间的最小时间。确保接收方在 SCL 上升沿到来时，SDA 上的数据已经完全稳定可读。这是影响最高通信速度的关键参数之一。
⚠️ tHD;DAT 有上限！ 这一点很多人忽略。tHD;DAT 不仅有最小值（防止数据过早变化），还有最大值（SM ≤ 3.45µs，FM ≤ 0.9µs）。如果 SCL 落下后 SDA 迟迟不变化，可能导致对端（或总线监听者）误判为 STOP 条件！
ACK / NAK 时序 ACKNOWLEDGE
每传输完 8 个数据位后，紧跟第 9 个时钟脉冲。此时控制权交给接收方：接收方拉低 SDA = ACK（确认），保持高 = NAK（不确认/结束）。

// 第 8 位数据 → ACK → 下一字节开始 的完整时序

ACK（Acknowledge，确认）

接收方在第 9 个 SCL 脉冲期间，将 SDA 拉低（LOW）。

主机写数据时：从机 发出 ACK，表示"收到了，继续！"

主机读数据时：主机 发出 ACK，表示"给我更多数据"；发出 NAK，表示"已够，请停止。"

NAK（Not Acknowledge，不确认）

接收方不拉低 SDA，保持高电平（依靠上拉电阻），即为 NAK。

NAK 可能意味着：① 地址错误，设备不存在；② 数据错误，拒绝接收；③ 主机读完最后一字节，通知从机停止；④ 设备忙碌，暂时无法响应。

💡 时钟拉伸（Clock Stretching）：从机如果处理太慢，可以在 ACK 位的 SCL 低电平期间将 SCL 继续拉低保持，强迫主机等待——这叫时钟拉伸。只有主机才能拉高 SCL；但从机可以强行延长低电平。主机在释放 SCL（让 SCL 上升）后，需要检测 SCL 是否真的变高，如果没有，说明从机在拉伸时钟，主机必须等待。
STOP 条件时序 STOP CONDITION
STOP 条件是通信的终止符，定义为：在 SCL 保持高电平期间，SDA 出现上升沿。执行 STOP 后，总线回到空闲状态，SDA 和 SCL 均为高。

// STOP 条件详细时序（含 tSU;STO 和 tBUF）

tSU;STO
Setup Time for STOP Condition
SM: ≥ 4.0 µs FM: ≥ 0.6 µs FM+: ≥ 0.26 µs
从 SCL 上升沿（SCL 变高）到 SDA 上升沿（STOP 事件）之间的最小时间。在此期间 SDA 必须保持低电平，确保所有设备都能在 SDA 上升前看到 SCL 是高的，从而正确识别 STOP 条件而不是普通数据位。
tBUF
Bus Free Time（重申）
SM: ≥ 4.7 µs FM: ≥ 1.3 µs FM+: ≥ 0.5 µs
STOP 完成（SDA 完全变高）到下一次 START 发起之间必须等待的最小时间。这段时间给了总线上的所有从设备恢复到空闲状态的机会，防止通信混叠。
重复 START（Repeated START） Sr
重复 START（Sr）允许主机在不释放总线的情况下，直接发起新的通信。常用于先写寄存器地址，再读取数据的场景（如读 I2C 传感器寄存器）。

// 写地址 → 写寄存器 → 重复START → 读数据 的完整时序

tSU;STA
Setup Time for Repeated START
SM: ≥ 4.7 µs FM: ≥ 0.6 µs FM+: ≥ 0.26 µs
从上一次 ACK 之后（SCL 低时 SDA 变高）到重复 START 的 SDA 下降沿之间，SCL 最后一次高电平的建立时间。必须给足时间，确保总线上所有设备都识别到"总线正在切换状态"而不是数据位。
tHD;STA（Sr）
Hold Time for Repeated START
SM: ≥ 4.0 µs FM: ≥ 0.6 µs FM+: ≥ 0.26 µs
从重复 START 的 SDA 下降沿（Sr 事件）到 SCL 下降沿之间的保持时间，与普通 START 的 tHD;STA 值相同。之所以单独标注 Sr，是因为重复 START 不需要 tBUF，可直接"插入"到通信流中。
💡 重复 START 最典型的使用场景（读寄存器）：
① 发 START + 设备地址（写模式）→ ACK
② 发目标寄存器地址 → ACK
③ 发 重复 START（Sr） + 设备地址（读模式）→ ACK
④ 从机发数据 → 主机 ACK → ... → 主机 NAK + STOP

使用 Sr 而不是 STOP+START 的好处：不释放总线控制权，防止其他主机（多主机系统中）在中间抢占总线，保证寄存器地址和读操作的原子性。

上拉电阻计算

上拉电阻 Rp 选值需同时满足最大和最小约束：

Rp(min) = (VCC - VOL) / IOL
确保驱动器能将信号拉低至 VOL 以下。

Rp(max) = tr / (0.8473 × Cb)
确保 RC 上升沿快到满足 tr 要求。

实际工程：SM 用 4.7kΩ，FM 用 1~2.2kΩ。

调试检查清单

① 示波器看 tr：过慢 → 减小上拉电阻
② 看 tHIGH 期间 SDA 是否稳定：抖动 → 电容太大或PCB走线太长
③ 确认 ACK 时刻 SDA 是否被拉低：未拉低 → NAK，地址错误
④ 时钟拉伸：SCL 低电平异常长 → 从机正在拉伸
⑤ 总线死锁：SDA 卡死 LOW → 需发 9 个时钟脉冲解锁
